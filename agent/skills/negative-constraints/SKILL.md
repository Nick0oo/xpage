# Restricciones negativas · v1.1.0

## Propósito
Prevenir contenido inventado, patrones visuales dañinos y promesas que el brief no respalda.

## Procedimiento
1. Extrae prohibiciones expresas, límites de marca y requisitos legales o de accesibilidad proporcionados.
2. Distingue hechos con fuente, hipótesis y datos faltantes.
3. Revisa cifras, testimonios, logos, premios, garantías, precios, disponibilidad y comparaciones.
4. Define límites de contraste, movimiento, foco, semántica, controles y contenido alternativo.
5. Audita el plan final contra cada restricción y elimina o marca lo no verificable.

## Entrega y verificación
Completa `negativeConstraints` con controles verificables y `claims` con fuente/estado. Una ausencia de fuente no se resuelve escribiendo una afirmación más cauta: elimina el claim o solicita el dato. Registra riesgos restantes de forma breve.

## Ejemplo
Si no hay reseñas en el brief, no crear estrellas, citas ni cifras de satisfacción; reservar ese espacio para explicar el proceso real.
