# Ficha de investigación · Prompts ambiciosos

Versión: 1.0.0 · 2026-09-28

## Definición y uso
Convierte motivaciones y objeciones posibles en una narrativa útil para la página. Conviene cuando el brief describe una audiencia, pero no aporta investigación de usuarios.

## Entradas, procedimiento y entrega
Entradas: oferta, audiencia y CTA. Formular motivaciones como hipótesis, mapear cada sección a una necesidad y usar solo pruebas entregadas para respaldar promesas. Entregar mapa de motivaciones/objeciones, propósito por sección y CTA.

## Calidad, riesgos y ejemplo XPage
Calidad: cada hipótesis es comprobable en una futura entrevista o prueba. Riesgo: presentarla como conocimiento del público o afirmar mejoras de conversión sin datos. Ejemplo: “podría preocuparle el tiempo de preparación” queda como hipótesis para una app de cocina.

## Fuentes
- NN/g, [Usability: A 1990s look at 2020](https://www.nngroup.com/articles/usability-1990s-look-2020/) (investigar tareas y contexto; las hipótesis requieren validación).
- GOV.UK Service Manual, [User research](https://www.gov.uk/service-manual/user-research) (investigación con usuarios para conocer necesidades).
