# Ficha de investigación · Activos de imagen

Versión: 1.0.0 · 2026-09-28

## Definición y uso
Especifica la función narrativa y requisitos de cada imagen. Conviene cuando la página requiere un activo y el medio debe apoyar, sin sustituir, la información textual.

## Entradas, procedimiento y entrega
Entradas: sección, concepto, contenido disponible y espacio de diseño. Definir sujeto, encuadre, luz, proporción, punto focal, alternativa textual y uso; relacionar cada activo con un `MediaSlot`. Entregar especificación, no binario.

## Calidad, riesgos y ejemplo XPage
Calidad: intención discernible, recorte viable y alternativa que expresa información relevante. Riesgos: texto incrustado, imagen decorativa anunciada como contenido, o inventar evidencia visual. Ejemplo: fotografía contextual para una sección de producto con texto alternativo según su propósito.
